# Player Behavior Analytics - Python Pipeline

This folder contains the Python implementation reconstructed from the project report.

## Pipeline

```text
Minecraft / CoreProtect
        |
        v
SQLite database
        |
        v
ingest.py
        |
        v
data/raw/*.csv
        |
        v
clean.py
        |
        v
data/clean/*.csv
        |
        v
transform.py
        |
        v
data/output/player_metrics.csv
        |
        v
analytics.py
        |
        v
data/output/final_analytics.csv
        |
        v
Power BI
```

## Run with real CoreProtect data

Place the database here:

```text
plugins/CoreProtect/database.db
```

Install dependencies:

```bash
pip install pandas
```

Run the complete pipeline:

```bash
python scripts/run_pipeline.py
```

## Run without the Minecraft server

For demonstration/testing only:

```bash
python scripts/generate_sample_data.py
python scripts/clean.py
python scripts/transform.py
python scripts/analytics.py
```

The sample generator creates CSV files with the same structure expected by the pipeline.

## Important

The original project report describes the CoreProtect database as the raw source and Power BI as the final visualization layer. The Python files here reproduce the documented ETL, metric, behavior-classification, and churn-prediction logic.

The actual Power BI `.pbix` file is not generated by these scripts.
